Participación 1: Partes de una página web

En esta actividad aprendí que una página web está formada por distintas partes que ayudan a organizar la información y facilitan la navegación. Identifiqué que el encabezado contiene el logo y el menú, mientras que el menú permite acceder a las diferentes secciones del sitio. También comprendí que las imágenes hacen la página más atractiva y que el contenido es la información principal que se muestra al usuario.

Aprendí que la página de inicio es la primera que aparece al entrar al sitio y que el pie de página incluye información de contacto y redes sociales. Además, entendí que el logo representa la identidad de la página, los CTA invitan a realizar acciones como registrarse o comprar, el blog sirve para compartir información y los formularios permiten ingresar datos. Finalmente, elaboré una maqueta para identificar la ubicación de cada elemento dentro de una página web.

Tarea 1: Selectores en CSS

En esta actividad aprendí qué son los selectores en CSS y cómo se utilizan para dar estilo a los elementos de una página web. Comprendí que son una parte importante del diseño web, ya que permiten seleccionar de manera específica los elementos HTML que se desean modificar. También identifiqué los principales tipos de selectores, como el universal, de tipo, descendiente, hijo, adyacente, de atributos, de clase y de ID, entendiendo que cada uno funciona de forma diferente según la estructura del documento. Además, realicé ejemplos prácticos de cada selector para comprender mejor cómo se aplican en el desarrollo de páginas web.
