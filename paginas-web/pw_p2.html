Tarea 2: Maquetación de una página web

En esta actividad copié y pegué los códigos de mis archivos HTML y CSS en un documento en blanco y tomé capturas de pantalla de la maquetación en el navegador para comprobar su funcionamiento.

La página quedó organizada con un encabezado dividido en tres partes, un menú de navegación, un main con tres secciones y un pie de página, lo que me permitió comprender mejor cómo se estructura una página web de manera ordenada.

Además, aprendí a utilizar HTML y CSS para organizar correctamente los elementos y mejorar la distribución del contenido dentro de una página web.

Tarea 3: Propiedades de CSS para el Menú de navegación.

En esta actividad revisé un archivo de Classroom sobre las propiedades de CSS e identifiqué aquellas que ayudan a mejorar el estilo del menú de navegación. También copié mis códigos HTML y CSS en un documento y tomé capturas de pantalla de mi página para comprobar el diseño aplicado.

Gracias a esta actividad, aprendí a utilizar CSS para mejorar la apariencia y organización del menú de navegación dentro de una página web.
